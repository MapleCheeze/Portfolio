# Keshawn White - Personal Portfolio

Personal portfolio site built with Jekyll and the [Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes) theme.

## About

A simple personal site with an about me landing page and a portfolio section showcasing my cybersecurity projects and professional work.

## Local Development

```bash
bundle install
bundle exec jekyll serve
```

Then visit `http://localhost:4000` in your browser.
